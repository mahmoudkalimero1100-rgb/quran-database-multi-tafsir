# Guide de Contribution 🤝

Merci de l'intérêt que vous portez à l'amélioration de cette base de données ! Voici comment vous pouvez aider.

## 🐛 Signaler une erreur
Si vous trouvez une faute d'orthographe dans un texte ou une erreur dans un Tafsir :
1. Ouvrez une **Issue** sur GitHub.
2. Décrivez précisément la sourate et le verset concernés.
3. Fournissez si possible une source fiable pour la correction.

## ✨ Proposer des ajouts
Vous souhaitez ajouter un nouveau Tafsir ou une nouvelle langue ?
1. Discutez de votre idée dans une **Issue** avant de commencer.
2. Si la proposition est validée, vous pouvez soumettre une **Pull Request** avec les modifications du script de génération ou de la base.

## 🛠️ Règles techniques
* Gardez le format **SQLite 3**.
* Toute nouvelle donnée textuelle doit être encodée en **UTF-8**.
* Les index SQL doivent être conservés pour garantir la rapidité de recherche.

Qu'Allah vous récompense pour votre aide !
